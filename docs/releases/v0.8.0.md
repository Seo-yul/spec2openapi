# spec2openapi v0.8.0

[한국어 릴리즈 노트](v0.8.0.ko.md)

Every converted operationId is the exact tool name FastMCP 4 exposes, and
`verify()` checks the names FastMCP actually produces. `agentize` keeps the
lines `minify_for_mcp` folds in, stops before its first model call when no
answer could make the result pass `verify()`, and type-checks examples on
structured fields.

## Highlights

**Tool name == operationId on FastMCP 4.** FastMCP 4 derives a tool's name
from its operationId: the part before the first `__`, slugified, truncated
to 56 characters, with a `_2` suffix on a duplicate. Converted operationIds
— from WSDL and from Swagger — are generated in the form it exposes
unchanged: `[A-Za-z0-9_]`, unique, at most 56 characters, no double or edge
underscores. Every change to a source operationId is recorded in
`x-s2o.assumptions`.

**`verify()` checks the names FastMCP produces.**

- `tool-name.length` (new, also in `check_fastmcp_ready()`) fails an
  operationId whose tool name FastMCP would truncate.
- `tool-name.present` fails an operationId that leaves an empty tool name,
  such as `__internal` or `-`.
- `tool-name.normalization-collision` and `tool-name.normalized` follow
  FastMCP 4's naming, the `__` split included.
- `fastmcp.tool-materialized` checks that each tool is exposed under the
  name derived from its operationId.

## `agentize`

**Fold lines survive a rewrite.** When `agentize` writes a new operation
description, the `Errors: ...` / `Example ...:` lines that `minify_for_mcp`
folded in stay at the end, once — even if the model repeats them.
`--rename-tools` moves the `x-s2o.minify.folded` record to the new
`operationId`, so a later minify neither drops nor duplicates those lines,
chained and swapped renames included.

**Checked before the first call.** An input that fails `verify()` in a way
the run cannot fix is rejected before any model call, and `--dry-run` says
so. Fields the run fills — an empty `description:` or a low-value
`summary`, for instance — and, with `--rename-tools`, a missing or
rule-breaking `operationId` on an operation it queries are left for the
run to fix.

**Renames follow the tool-name rules.** `--rename-tools` applies only names
FastMCP 4 exposes unchanged.

**Typed examples on structured fields.** An `array` / `object` property
gets an example only when it parses as finite JSON of that shape within
the size cap, with control characters removed from the parsed value, keys
included. A field whose type comes from `$ref` or an untyped `allOf` /
`oneOf` / `anyOf` gets none.

**Exit status.** `spec2openapi agentize` exits 2 with "모든 LLM 호출이 실패"
only when none of the calls that produce suggestions answered; a run where
some did writes its output.

## Breaking changes

**Converted operationIds.** An operationId that FastMCP 4 would expose under
a different name — longer than 56 characters, containing `__`, or with a
leading or trailing `_` — is converted to a name it exposes unchanged. The
tools behind those operations may be exposed under new names;
`x-s2o.assumptions` lists every change.

**`validate` fails on names FastMCP rewrites into something unusable.**
`spec2openapi validate` and `check_fastmcp_ready()` fail on an operationId
whose tool name FastMCP would truncate or leave empty.

## Install

```bash
pip install --upgrade spec2openapi

# optional extras
pip install 'spec2openapi[mcp]'             # SOAP bridge + FastMCP 4 runtime
pip install 'spec2openapi[llm-anthropic]'   # agentize, Claude
pip install 'spec2openapi[llm-openai]'      # agentize, OpenAI
```

Python 3.10+. Full detail in [CHANGELOG.md](../../CHANGELOG.md).
