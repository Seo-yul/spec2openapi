# spec2openapi v0.5.0

[English release notes](v0.5.0.md)

MCP 표면을 다듬은 릴리즈다. 새 선택적 후처리 함수가 FastMCP로 서빙되는
tool 페이로드를 더 작고 더 유용하게 만들고, 대형 서비스에서 tool 개수를
제어하는 방법이 문서에 추가됐다.

## 하이라이트

**`minify_for_mcp` — 모델이 실제로 보는 것을 줄이고 채운다.** 스펙을
MCP로 서빙하면 LLM은 OpenAPI 문서를 읽지 않는다. 모델에게 도달하는 것은
각 tool의 `name`, `description`, `inputSchema`, `outputSchema`뿐이다.
새 후처리 함수는 정확히 그 표면을 다룬다. 변환 파이프라인은 그대로이고,
원하는 사용자만 한 줄을 더 부른다.

```python
spec = spec2openapi.convert_swagger(legacy)      # 또는 convert_wsdl(...)
spec = spec2openapi.minify_for_mcp(spec, enrich=("errors", "examples"))
```

- **줄이기**: 보존 목록에 없는 벤더 `x-*` 확장을 스키마 서브트리에서
  제거한다. FastMCP가 tool 스키마로 그대로 복사하는 위치들이기
  때문이다. 런타임과 독자가 필요로 하는 것은 전부 살아남는다.
  `x-soap*`와 `x-text`를 포함한 `xml` 어노테이션, `x-s2o`,
  `x-fastmcp-*`, 손실 보존용 `x-pattern`/`x-collectionFormat`,
  `x-enum-varnames` 같은 문서성 확장이 그렇고, 자체 확장은
  `keep_extensions=`로 지킨다. `max_description`과
  `drop_value_examples`는 명시적으로 켜는 축소 옵션이다.
- **채우기**: MCP tool 형태에서 잘려 나가는 정보를 모델이 항상 보는
  유일한 채널로 되살린다. `"errors"`는 에러 응답을
  `Errors: 404 (order not found); 409 (duplicate).` 형태의 한 줄로
  description에 접어 넣고, `"examples"`는 request/response 페이로드
  example을 한 줄 JSON으로 접으며 파라미터 수준 `example` 값을 스키마
  안으로 옮겨 `inputSchema`에서 보이게 한다. 문서에 이미 있는 사실만
  사용하므로 아무것도 지어내지 않고, 다시 실행해도 중복으로 접히지
  않는다.

어떤 옵션 조합에서도 결과물은 유효한 FastMCP-ready OpenAPI 문서로 남고
동일하게 서빙된다(SOAP envelope은 바이트 단위로 같다). 함수는 결정적이고
멱등적이며, 제거되거나 접힌 내용은 `x-s2o.minify`에 요약된다. 하드닝
감사에서 실전 문서의 형태들을 점검했다. 순환 스키마와 앵커로 공유된
스키마, OpenAPI 3.1의 하위 스키마 키워드, 와일드카드 에러 범위, 잘못
전달된 인자 형태가 모두 전용 회귀 테스트로 고정됐고, FastMCP 업그레이드로
페이로드 도달 위치가 바뀌면 시끄럽게 실패하는 누출 지도 테스트도 있다.

**tool 개수 제어를 문서화했다.** 대형 서비스에서 지배적인 컨텍스트
비용은 tool의 크기가 아니라 개수다. MCP 클라이언트는 `tools/list` 결과
전체를 매 요청마다 모델 컨텍스트에 싣기 때문이다. README에 검증된
서브셋 서빙 패턴을 추가했다. FastMCP route map이
`from_openapi_spec(...)`으로 그대로 통과되고, 제외된 operation은 호출
자체가 들어오지 않으므로 SOAP 브리지도 그대로 동작하며, WSDL에서 변환된
스펙은 모든 operation에 서비스 이름이 태그로 붙어 있어 서비스 단위
서브셋에 별도 태깅이 필요 없다.

## 설치

```bash
pip install spec2openapi          # 변환기 + CLI (Python 3.10+)
pip install "spec2openapi[mcp]"   # + SOAP 브리지 (SOAP 서빙에 필수)
```

## 변경 내역

- MCP tool 페이로드를 줄이고 채우는 minify_for_mcp 추가 (#129)
- FastMCP route map 통과를 이용한 tool 개수 제어 문서화 (#131)
