# spec2openapi v0.8.0

[English release notes](v0.8.0.md)

변환된 operationId는 FastMCP 4가 노출하는 tool 이름과 정확히 같고,
`verify()`는 FastMCP가 실제로 만드는 이름을 검사한다. `agentize`는
`minify_for_mcp`가 접어 넣은 줄을 지우지 않고, 어떤 응답으로도 결과가
`verify()`를 통과할 수 없는 입력은 첫 모델 호출 전에 멈추며, 구조형 필드의
example은 type을 검사한다.

## 하이라이트

**FastMCP 4에서 tool 이름 == operationId.** FastMCP 4는 operationId에서
tool 이름을 만든다 — 첫 `__` 앞부분만 쓰고, 정규화한 뒤, 56자로 자르며,
중복되면 `_2`를 붙인다. WSDL과 Swagger에서 변환한 operationId는 FastMCP가
그대로 노출하는 형태로 생성한다. `[A-Za-z0-9_]`만 쓰고, 중복이 없고, 56자
이하이며, 밑줄을 연달아 쓰거나 앞뒤에 쓰지 않는다. 원본 operationId를 바꾼
내역은 모두 `x-s2o.assumptions`에 기록된다.

**`verify()`는 FastMCP가 만드는 이름을 검사한다.**

- `tool-name.length`(신규, `check_fastmcp_ready()`에도 포함)는 FastMCP가
  잘라낼 tool 이름을 남기는 operationId를 실패로 본다.
- `tool-name.present`는 `__internal`, `-`처럼 tool 이름이 비는 operationId를
  실패로 본다.
- `tool-name.normalization-collision`과 `tool-name.normalized`는 `__` 분할을
  포함한 FastMCP 4의 규칙을 따른다.
- `fastmcp.tool-materialized`는 각 tool이 operationId에서 만든 이름으로
  노출되는지 확인한다.

## `agentize`

**접힌 줄은 설명을 새로 써도 남는다.** `agentize`가 operation 설명을 새로
쓰면 `minify_for_mcp`가 접어 넣은 `Errors: ...` / `Example ...:` 줄은 끝에
한 벌만 남는다 — 모델이 그 줄을 되풀이해도 마찬가지다. `--rename-tools`는
`x-s2o.minify.folded` 기록을 새 `operationId`로 옮기므로, 이어서 돌린
minify가 그 줄을 지우거나 두 번 붙이지 않는다. 이어진 개명과 맞바꾼 개명도
같다.

**첫 호출 전에 검사한다.** 실행으로 고칠 수 없는 방식으로 `verify()`를
통과하지 못하는 입력은 모델을 호출하기 전에 거부하며, `--dry-run`도 이를
알린다. 이번 실행이 채우는 필드(값이 빈 `description:`, 저품질 `summary`
등)와, `--rename-tools`를 쓸 때 질의하는 operation의 빠졌거나 규칙을
어기는 `operationId`는 실행이 고치도록 남겨 둔다.

**개명은 tool 이름 규칙을 따른다.** `--rename-tools`는 FastMCP 4가 그대로
노출하는 이름만 적용한다.

**구조형 필드의 example은 type을 맞춘다.** `array`/`object` 속성에는 크기
상한 안에서 그 모양의 유한한 JSON으로 파싱되는 example만 쓰고, 파싱한 값의
제어문자는 키까지 지운다. type을 `$ref`나 type 선언 없는
`allOf`/`oneOf`/`anyOf`에서 가져오는 필드에는 example을 쓰지 않는다.

**종료 코드.** `spec2openapi agentize`는 제안을 만드는 호출이 하나도
응답하지 않았을 때만 "모든 LLM 호출이 실패"로 종료 코드 2를 낸다. 일부라도
응답한 실행은 산출물을 쓴다.

## 호환성이 깨지는 변경

**변환된 operationId.** FastMCP 4가 다른 이름으로 노출할 operationId —
56자를 넘거나, `__`를 담거나, 앞뒤에 `_`가 있는 것 — 는 FastMCP가 그대로
노출하는 이름으로 변환된다. 그 operation의 tool은 새 이름으로 노출될 수
있으며, 바뀐 내역은 모두 `x-s2o.assumptions`에 있다.

**`validate`는 FastMCP가 쓸 수 없게 바꾸는 이름에서 실패한다.**
`spec2openapi validate`와 `check_fastmcp_ready()`는 FastMCP가 tool 이름을
잘라내거나 비게 만드는 operationId에서 실패한다.

## 설치

```bash
pip install --upgrade spec2openapi

# 선택 extra
pip install 'spec2openapi[mcp]'             # SOAP 브리지 + FastMCP 4 런타임
pip install 'spec2openapi[llm-anthropic]'   # agentize, Claude
pip install 'spec2openapi[llm-openai]'      # agentize, OpenAI
```

Python 3.10+. 자세한 내역은 [CHANGELOG.md](../../CHANGELOG.md)에 있다.

## 변경 목록

- agentize: fold 기록, 호출 전 verify, example type 검사, 실패 판정 (#154)
- operationId를 FastMCP 4가 노출하는 tool 이름으로 생성(56자 상한), verify는 이름을 비교 (#156)
